# Вариант 2

1. Создать файл input.txt, в который поместить 2 случайные матрицы размера, заданного пользователем. Закрыть файл. Очистить массивы.

2. Открыть input.txt файл и прочитать матрицы, произвести их перемножение и сложение (с помощью функций), вывести результат в файл output.txt.

3. Поменять местами пары элементов в матрице1 из файла output.txt.

4. Найти номер минимального элемента в матрице1 и найти количество нечетных чисел в ней.

5. Найти матрицу с одинаковыми числами в строке или столбце.

6. Замерить время работы программы и вывести на экран.
